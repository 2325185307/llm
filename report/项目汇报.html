Component 01

宠物医院 MCP

Go 标准库本地服务 + Python MCP 适配层，把宠物医院业务能力开放为 MCP 工具。

Go 后端 :8080

  • 内嵌网页：档案增删改查、搜索筛选、病历与消费明细、经营统计
  • 29 个 REST 接口：CRUD、全文检索、批量、导出 JSON/CSV、压实
  • 单文件嵌入式数据库：append-only 日志 + CRC32 校验 + 自动压实 + 崩溃自愈
  • 零第三方依赖：仅标准库，单文件可迁移

MCP 适配 :8000/mcp

  • Python 实现，将 REST 能力映射为 16 个 MCP 工具
  • 档案 CRUD、病历/收费追加、统计导出、批量删除、数据库压实
  • 工具名规范化，参数 Schema 完整，可供任意 MCP 客户端调用

MCP 工具一览（16 个）

list_pets / get_pet create_pet / update_pet patch_pet / delete_pet search_pets / get_stats list_pet_records / add_pet_record list_pet_charges / add_pet_charge get_pet_summary / export_pets compact_database / batch_delete_pets

Component 02

AnythingLLM MCP

基于官方 MCP SDK 2.x，把 AnythingLLM 工作区能力暴露为 MCP 工具。

服务实现

  • 使用 mcp.server.MCPServer + Pydantic 输入模型
  • Streamable HTTP 协议，无状态模式（stateless）
  • 端点 http://127.0.0.1:8081/mcp，健康检查 /health
  • 连接信息通过环境变量注入，不写死密钥

四个 MCP 工具

  • ask_workspace — 向工作区提问，返回 AI 回答
  • get_workspace — 工作区配置 / 文档 / 线程摘要
  • list_workspace_chats — 聊天记录（分页 / 排序）
  • vector_search — 文档向量相似度检索

关键点

  • 严格遵循 MCP 协议规范（含 initialize / list_tools / call_tool），可直接被 MCP Inspector 或 SDK 客户端连接
  • 端口默认 8081，避免与宠物医院 Go 后端 8080 冲突

Component 03

AnythingLLM 网页 · 文档工作台

单文件 HTML 前端，把本地资料批量上传到 AnythingLLM 工作区。

核心功能

  • 拖拽 / 选择文件，批量上传，单文件最大 50 MB
  • 自动加载并选择 目标工作区（slug）
  • 连接状态指示灯 + 工作区数量 / 待传 / 完成统计
  • 上传队列（待传 / 上传中 / 成功 / 失败）与移除
  • 最近活动记录（localStorage 持久化）

技术细节

  • 纯原生 HTML/CSS/JS，零框架依赖，打开即用
  • 调用 AnythingLLM API：/v1/workspaces、/v1/document/upload
  • Bearer Token 仅存内存，不写入文件
  • 响应式布局，移动端可用

支持的文件格式

PDFTXTMarkdown Word (.doc/.docx)CSVJSON HTMLExcel (.xlsx/.xls)

Component 04

心理咨询 Agent · xAgent

「心安」——CBT 取向心理咨询师，全屏 TUI，内置 6 个咨询技能并编排 MCP 工具。

咨询能力

  • 人设：温暖、共情、非评判，协作式引导而非说教
  • 6 个咨询技能：CBT 治疗师、心理健康、心理健康助手、治疗师筛查、亲密关系治疗、治疗流派
  • 安全边界：自杀 / 自伤念头立即转介危机干预热线 400-161-9995
  • 结构化流程：评估 → 探索（认知重构 / 苏格拉底提问）→ 反馈与家庭作业

工程机制

  • loadSkill 按需加载技能全文与参考文件
  • recallContext 历史上下文检索
  • MCP × 20 动态并入宠物医院 / AnythingLLM 工具
  • 上下文压缩：70% 阈值触发，原上下文归档 .agents/context/
  • 会话持久化：JSONL 存 .agents/sessions/，可 /resume 恢复

TUI 界面与配置

左侧对话、右侧状态边栏（上下文用量 / MCP 服务器与工具 / 斜杠命令）。斜杠命令：/new /resume /save /compact /clear /help /skills /mcp /quit；参数全部走 config.ini，缺失自动生成 mock 模板；MCP 异步加载，先进入界面再动态刷新边栏。
